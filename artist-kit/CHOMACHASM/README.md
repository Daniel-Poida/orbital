# CHOMACHASM: что прислать

Пример планеты, которая сейчас на сайте. Звуки в нём синтетические, их нужно заменить настоящими из трека. Общие требования — в [README](../README.md).

**Темп:** 100 BPM. Луп на 4 такта = 9,600 с.

## Звуки ударки

| Файл | Что записать |
|---|---|
| `drums/01 Бочка.wav` | бочка из трека |
| `drums/02 Снейр.wav` | малый барабан |
| `drums/03 Хэт.wav` | хай-хэт |
| `drums/04 Чайна.wav` | тарелка, крэш или чайна |
| `drums/05 Чаг.wav` | тяжёлый заглушённый удар гитары |
| `drums/06 Гроул.wav` | вокальный выкрик или гроул |
| `drums/07 Сирена.wav` | синт-сирена или тревожный звук |
| `drums/08 Лазер.wav` | короткий электронный эффект |
| `drums/09 Райзер.wav` | нарастание |
| `drums/10 Бездна.wav` | очень низкий удар, саб, «падение в пропасть» |

## Картинки

- `textures/planet.png` — поверхность планеты. В примере 512×512, для настоящей лучше 2048×1024.
- `textures/background.png` — фон экрана. В примере PNG 512×512, для настоящего нужен вертикальный JPG 1080×1920.

Слоты и подписи можно менять: переименуйте файл, уберите лишний или добавьте свой с новым номером.
