# Exploration One: что прислать

Пример планеты, которая сейчас на сайте. Звуки в нём синтетические, их нужно заменить настоящими из трека. Общие требования — в [README](../README.md).

**Темп:** 140 BPM. Луп на 4 такта = 6,857 с.

## Звуки ударки

| Файл | Что записать |
|---|---|
| `drums/01 Бочка.wav` | сухая плотная бочка из трека, без хвоста реверба |
| `drums/02 Снейр.wav` | малый барабан, можно с индустриальным призвуком |
| `drums/03 Хэт.wav` | закрытый хай-хэт, короткий |
| `drums/04 Чайна.wav` | тарелка чайна, удар с естественным затуханием |
| `drums/05 Чаг низ.wav` | заглушённый удар по нижней струне, «чаг» на основном строе |
| `drums/06 Чаг верх.wav` | тот же чаг на ступень или квинту выше |
| `drums/07 Скрим-флажолет.wav` | пинч-гармоника или визг гитары |
| `drums/08 Индастриал-хит.wav` | металлический удар, лязг, семпл из саунд-дизайна трека |
| `drums/09 Саб-дроп.wav` | низкий саб с падением высоты |
| `drums/10 Глитч.wav` | короткий цифровой щелчок или звук-глитч |

## Лупы (кольца)

| Файл | Длина | Что записать |
|---|---|---|
| `loops/01 Джент-рифф (4 такта).wav` | 6,857 с | основной рифф трека, гитары без барабанов |
| `loops/02 Космо-пад (4 такта).wav` | 6,857 с | атмосферный пад или синт-подложка |
| `loops/03 Лид (4 такта).wav` | 6,857 с | лид-гитара или главная мелодия |
| `loops/04 Индастриал-дрон (4 такта).wav` | 6,857 с | шумовой гул, текстура, дрон |
| `loops/05 Арп (4 такта).wav` | 6,857 с | арпеджио синта или чистой гитары |
| `loops/06 Ударные (4 такта).wav` | 6,857 с | барабанная партия трека отдельной дорожкой |

## Картинки

- `textures/planet.png` — поверхность планеты. В примере 512×512, для настоящей лучше 2048×1024.
- `textures/background.png` — фон экрана. В примере PNG 512×512, для настоящего нужен вертикальный JPG 1080×1920.

Слоты и подписи можно менять: переименуйте файл, уберите лишний или добавьте свой с новым номером.
