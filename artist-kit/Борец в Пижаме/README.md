# Борец в Пижаме: что прислать

Пример планеты, которая сейчас на сайте. Звуки в нём синтетические, их нужно заменить настоящими из трека. Общие требования — в [README](../README.md).

**Темп:** 118 BPM. Луп на 4 такта = 8,136 с.

## Звуки ударки

| Файл | Что записать |
|---|---|
| `drums/01 Бочка.wav` | бочка из трека |
| `drums/02 Снейр.wav` | малый барабан |
| `drums/03 Хэт.wav` | хай-хэт |
| `drums/04 Рим.wav` | римшот, удар по ободу |
| `drums/05 Клэп.wav` | клэп или щелчок |
| `drums/06 Бубен.wav` | бубен или шейкер |
| `drums/07 Гитара.wav` | одна нота или аккорд гитары |
| `drums/08 Синт-плак.wav` | короткая синт-нота |
| `drums/09 Оу.wav` | вокальное «оу» или короткое слово из песни |
| `drums/10 Реверс.wav` | реверсный звук, вдох, переход |

## Лупы (кольца)

| Файл | Длина | Что записать |

| `loops/01 Неон-пад (4 такта).wav` | 8,136 с | подложка, аккорды |
| `loops/02 Бас (4 такта).wav` | 8,136 с | басовая партия |
| `loops/03 Гитарный арп (4 такта).wav` | 8,136 с | гитарный перебор или арпеджио |
| `loops/04 Оу-хор (4 такта).wav` | 8,136 с | бэк-вокал, хор |
| `loops/05 Клавиши (4 такта).wav` | 8,136 с | клавишные, аккорды |
| `loops/06 Ударные (4 такта).wav` | 8,136 с | барабанная партия трека отдельной дорожкой |

## Картинки

- `textures/planet.png` — поверхность планеты. В примере 512×512, для настоящей лучше 2048×1024.
- `textures/background.png` — фон экрана. В примере PNG 512×512, для настоящего нужен вертикальный JPG 1080×1920.

Слоты и подписи можно менять: переименуйте файл, уберите лишний или добавьте свой с новым номером.
