# Pigeon Slayers: что прислать

Пример планеты, которая сейчас на сайте. Звуки в нём синтетические, их нужно заменить настоящими из трека. Общие требования — в [README](../README.md).

**Темп:** 130 BPM. Луп на 4 такта = 7,385 с.

## Звуки ударки

| Файл | Что записать |
|---|---|
| `drums/01 Бочка.wav` | бочка из трека, плотная, без хвоста |
| `drums/02 Снейр.wav` | малый барабан |
| `drums/03 Чайна.wav` | тарелка чайна |
| `drums/04 Бласт.wav` | короткий бласт-бит, полсекунды |
| `drums/05 Брейкдаун.wav` | один тяжёлый удар брейкдауна |
| `drums/06 Визг.wav` | пиг-сквил или визг вокала |
| `drums/07 Голубь.wav` | воркование голубя, фирменный звук проекта |
| `drums/08 Крылья.wav` | хлопанье крыльев |
| `drums/09 Гроул.wav` | короткий гроул, одно слово или выкрик |
| `drums/10 Хэт.wav` | закрытый хай-хэт |

| `loops/02 Тремоло (4 такта).wav` | 7,385 с | тремоло-рифф |

| `loops/06 Голубиный хор (4 такта).wav` | 7,385 с | бэк-вокал, хор, «голубиная» партия |

## Картинки

- `textures/planet.png` — поверхность планеты. В примере 512×512, для настоящей лучше 2048×1024.
- `textures/background.png` — фон экрана. В примере PNG 512×512, для настоящего нужен вертикальный JPG 1080×1920.

Слоты и подписи можно менять: переименуйте файл, уберите лишний или добавьте свой с новым номером.
