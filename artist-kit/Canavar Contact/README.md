# Canavar Contact: что прислать

Пример планеты, которая сейчас на сайте. Звуки в нём синтетические, их нужно заменить настоящими из трека. Общие требования — в [README](../README.md).

**Темп:** 128 BPM. Луп на 4 такта = 7,500 с.

## Звуки ударки

| Файл | Что записать |
|---|---|
| `drums/01 808.wav` | 808-бочка с длинным басовым хвостом |
| `drums/02 Снейр.wav` | индустриальный снейр |
| `drums/03 Хэт.wav` | короткий хэт |
| `drums/04 Клэп.wav` | клэп |
| `drums/05 Стаб.wav` | синт-стаб, аккорд одним ударом |
| `drums/06 Чаг.wav` | заглушённый гитарный удар |
| `drums/07 Сирена.wav` | сирена или тревожный синт-звук |
| `drums/08 Райзер.wav` | нарастающий подъём перед дропом |
| `drums/09 Хэй.wav` | вокальный выкрик «хэй» или другая фраза |
| `drums/10 Лазер.wav` | лазер, зап, пиу |

## Картинки

- `textures/planet.png` — поверхность планеты. В примере 512×512, для настоящей лучше 2048×1024.
- `textures/background.png` — фон экрана. В примере PNG 512×512, для настоящего нужен вертикальный JPG 1080×1920.

Слоты и подписи можно менять: переименуйте файл, уберите лишний или добавьте свой с новым номером.
