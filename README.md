# Orbital

Орбитальный семплер для промо треков: планета артиста, орбиты с спутниками-семплами и кольца с длинными лупами. Статический сайт без сервера: HTML, three.js для 3D и Tone.js для звука. Работает на iOS и Android по ссылке, без установки.

## Запуск локально

```
cd work/orbital
/usr/bin/python3 -m http.server 8765
```

Открыть http://localhost:8765/. На телефоне в той же сети: http://<ip-компьютера>:8765/.

## Как играть

- Выбери спутник внизу и нажми на точку орбиты, или перетащи спутник на орбиту.
- Повторное нажатие тем же спутником снимает его. Нажатие на спутник без выбора тоже снимает.
- Кольца включаются чипом внизу или нажатием на само кольцо вокруг планеты.
- Нажатие на планету запускает и останавливает всё.
- Плюс и минус добавляют и убирают орбиты, до 16 штук. Щипок двумя пальцами приближает, одним пальцем по пустому месту двигает вид, двойное нажатие возвращает вид.
- Нижняя панель разбита на вкладки: «Звуки» (спутники), «Кольца», «Микшер» и «Мастер».
- «Микшер»: у каждого кольца и каждого звука ударки своя громкость, индикатор уровня, заглушение, у колец включатель. Кнопка «FX» открывает эффекты канала: фильтр, перегруз (драйв), посыл на реверб и на дилей.
- «Мастер»: общая громкость, фильтр, размер реверба, повторы и шаг дилея, ширина стерео.
- «Поделиться» даёт ссылку, в которой зашита расстановка спутников, колец, микшер и мастер.

## Редактор планет

В списке планет есть кнопка «Создать свою планету» (или адрес `#edit`). Редактор работает прямо в браузере, сервера не нужно:

- название планеты, название песни (подпись под названием), темп, ссылка на трек;
- текстура планеты и фон экрана картинками с устройства;
- четыре цвета интерфейса;
- до 12 звуков ударки и до 8 колец, файлы выбираются с телефона или компьютера, каждый можно прослушать;
- для колец показывается длина в тактах при заданном темпе, число тактов подставляется само;
- «Проверить в сцене» загружает черновик в обычный режим игры, кнопка «Редактор» наверху возвращает обратно;
- «Взять за основу текущую планету» копирует открытую планету в черновик;
- «Скачать ZIP планеты» собирает папку с `planet.json` и файлами. Её кладут в `planets/`, строка для `index.json` лежит в архиве в `README.txt`.

Черновик вместе с файлами хранится в браузере (IndexedDB), так что можно вернуться позже.

## Планеты артистов

В `planets/` лежат четыре планеты, собранные под стиль артистов: Exploration One, Pigeon Slayers, Canavar Contact и Борец в Пижаме. Звуки в них синтетические, сделанные в духе жанра скриптом `tools/gen_artists.py`, а не записи самих артистов. Настоящие семплы подменяются через редактор или заменой файлов в папке планеты с правкой `planet.json`.

## Добавить планету артиста вручную

1. Создай папку `planets/<id>/` и положи туда:
   - `planet.png` — квадратная текстура планеты 512×512 (разворачивается на сферу, как карта мира);
   - `bg.png` — фон экрана, любой размер;
   - `samples/` — короткие семплы и длинные лупы.
2. Скопируй `planets/demo-a/planet.json` и поправь поля:
   - `bpm` — темп трека; лупы для колец должны быть записаны ровно в этом темпе;
   - `samples` — короткие звуки: `name`, `file`, `color`;
   - у звуков и колец можно задать `gain` в децибелах — стартовую громкость в микшере;
   - `rings` — длинные лупы: `file`, `bars` (длина в тактах, обычно 2 или 4), `color`; необязательно `mode: "resample"`, если кольцо должно менять высоту вместе с темпом, по умолчанию кольца растягиваются без смены высоты;
   - `colors.accent`, `colors.orbit`, `colors.ray`, `colors.text` — цвета интерфейса;
   - `trackUrl` — ссылка на полный трек.
3. Добавь строку с `id`, `name`, `track` в `planets/index.json`.

Формат файлов: WAV, m4a или ogg. Лупы для колец должны быть точной длины в тактах, иначе будет плыть сетка. Короткие семплы лучше до секунды.

Демо-ассеты генерируются скриптом `tools/gen_assets.py`, он нужен только для примеров.

## Публикация на GitHub Pages

Папка самодостаточна. Чтобы выложить:

1. Создать отдельный репозиторий, например `orbital`, и скопировать в него содержимое `work/orbital`.
2. В настройках репозитория включить Pages с веткой `main` и папкой `/ (root)`.
3. Через минуту сайт доступен по адресу `https://<аккаунт>.github.io/orbital/`.

Отдельные планеты можно давать ссылкой вида `https://<аккаунт>.github.io/orbital/#p=<id>`.

## Комплект для артистов

Папка `artist-kit/` — что прислать для планеты: общая инструкция, пустой шаблон и пример на каждого артиста (анкета, картинки, звуки ударки, лупы). Пример собирается из текущих планет командой `/usr/bin/python3 tools/make_kit.py`. Присланная артистом папка превращается в планету командой:

```
/usr/bin/python3 tools/kit_to_planet.py "artist-kit/<папка артиста>" <id-планеты>
```

## Структура

- `index.html`, `css/style.css` — разметка и стили;
- `js/scene.js` — 3D-сцена: планета, орбиты, кольца, спутники, луч, камера;
- `js/audio.js` — звук: шаговый секвенсор, лупы колец, канальные линейки с эффектами, мастер;
- `js/app.js` — состояние, интерфейс, вкладки, ссылка, жесты;
- `js/mixer.js` — микшер, эффекты каналов и мастер;
- `js/editor.js` — редактор планет и выгрузка ZIP;
- `planets/` — планеты артистов;
- `tools/gen_assets.py` — генератор демо-ассетов;
- `tools/gen_artists.py` — генератор планет артистов;
- `tools/make_kit.py` — сборка комплекта для артистов;
- `tools/kit_to_planet.py` — папка артиста в планету;
- `artist-kit/` — комплект для артистов.
